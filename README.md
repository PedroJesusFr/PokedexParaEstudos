# Minha Pokédex

Projeto de estudos utilizando HTML, CSS e JavaScript puro.

## Estrutura

- `index.html`: página principal
- `css/style.css`: estilos
- `js/main.js`: inicialização e eventos
- `js/api.js`: integração futura com a PokéAPI
- `js/ui.js`: renderização dos Pokémon
- `assets/images/`: imagens locais
- `assets/icons/`: ícones locais
